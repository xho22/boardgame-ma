# boardgame-ma

一个用于家庭本地同屏游玩、并预留固定房间在线扩展的网页竞速桌游项目。

## 当前开发原则

- 第一版先做本地同屏 2-6 人游玩。
- 不做购买/招募阶段，开局直接分配角色。
- 角色能力以 `rules/` 中的标准版资料为准。
- 规则引擎和 UI 分离，所有操作走可序列化 `GameCommand`。
- 未来在线版只做固定房间，不做账号和复杂多租户。
- 本地同屏与在线房间长期并存；本地模式始终可用于快速 Debug 与角色能力测试。
- 每次开发默认只推进一个阶段，并在结束时给出输出和验证结果。

## 当前进度

- 阶段 0-10 已完成；在线房间尚未开始。
- 本地模式支持 2-6 人；2-3 人局可让每名玩家每场派出 2 名 racer，行动顺序按玩家交错。
- Race Reveal 页面已支持 Mastermind 预测、鸡蛋三选一复制，以及双胞胎从历史第一名角色中选择复制能力。
- 开发服务器固定使用 `http://127.0.0.1:5173/`。

下一步与已知缺口以 [计划文档](./docs/PLAN.md) 的阶段验收表为准。
