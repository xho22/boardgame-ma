# Boardgame MA - 魔法竞速

一个为家庭共同游玩而制作的网页竞速桌游。每位玩家从随机分到的角色中秘密派出 racer，在四场比赛里掷骰、发动能力、穿越特殊棋盘，并累积总分争夺最终冠军。

项目同时保留两种玩法：面对面时使用本地同屏模式；两台设备时使用固定在线房间。两种模式共用同一套规则引擎，本地模式也始终是测试角色能力和 Debug 的快捷入口。

## 游戏内容

- 支持 2-6 名玩家；2-3 人时可选择每人每场派出 1 或 2 名 racer。
- 共进行 4 场比赛，按 `3/1`、`4/2`、`4/2`、`5/3` 分别奖励每场的第 1、2 名。
- 包含 36 名能力各异的 racer，开局随机分队、秘密选角，随后统一揭示。
- 默认第 1、3 场使用普通棋盘，第 2、4 场使用特殊棋盘；特殊格会得分、绊倒、前进或后退。
- Debug 模式可指定骰面，并可开启 `All Special`，让每一场都使用特殊棋盘。
- 比赛日志、逐格棋子动画、角色头像、能力悬停说明和主动能力选择均已实现。

## 开始游玩

### 本地同屏

启动开发环境后打开 `http://127.0.0.1:5173/`，在首页选择本地游戏，设置玩家人数与昵称后即可开始。

```bash
npm run dev
```

本地同屏不需要启动在线房间服务。

首页会显示构建时注入的“最后更新”时间（UTC+8），用于确认当前浏览器是否已经加载到新部署的版本。

### 在线固定房间

在线模式提供 `family-a` 至 `family-h` 共 8 个固定房间。两位玩家打开同一个页面后，选择相同房间、填写各自昵称；房主可设置每名玩家的 racer 数量、Debug 和棋盘模式，然后开始共享游戏。

开发时需分别启动前端与房间服务：

```bash
# 终端 1：网页开发服务器
npm run dev

# 终端 2：在线房间服务
npm run server
```

网页仍访问 `http://127.0.0.1:5173/`。它会将同源 `/ws` 自动代理到本机 `8787` 端口。在线房间进行中的比赛可由房主重置，所有玩家回到大厅重新开局。

## 生产运行

生产环境只运行一个进程、一个端口：

```bash
npm ci
npm run start
```

默认访问 `http://127.0.0.1:8787/`。该端口同时提供网页、`/health` 健康检查和同源 WebSocket `/ws`。可按需修改监听地址与端口：

```bash
HOST=127.0.0.1 PORT=8787 npm run start
```

若通过 Cloudflare Tunnel 发布域名，将服务填写为 `http://127.0.0.1:8787` 即可；HTTP 页面与 WebSocket 使用同一个公开域名，不需要单独配置 `ws://` 服务。更多配置见[部署文档](./docs/DEPLOYMENT.md)。

## 开发与验证

```bash
npm test
npm run build
npm run typecheck:server
npm run e2e
```

`npm test` 固定为单个 Vitest worker，避免在本机残留多个测试进程。开发服务器固定使用 `5173`，在线房间服务固定使用 `8787`。

## 当前边界

- 在线房间的规则、选角、比赛、反应和赛后流程均已接入服务端权威状态。
- 房间状态目前保存在 Node 内存；服务重启或重新部署会清空比赛。
- 固定房间名不是访问控制。公开发布前应增加房间口令或邀请码。
- 后续进度和验收缺口以[计划文档](./docs/PLAN.md)为准。
